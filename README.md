# Taste Test Journal

A simple portable web app for tracking cannabis strains you try.

## Features

- Log strain name, purchase date, packaged date, rating, notes, THC %, CBD %, and terpenes %.
- Add custom percentage fields (for example CBG, CBN, etc.).
- Search, filter, and sort from the dashboard.
- Export/import your database as a JSON file so you can move it to another computer.
- Quick outbound search links for Canna Cabana and Delta 9.

## Run locally

```bash
python3 -m http.server 4173
```

Then open <http://localhost:4173>.
