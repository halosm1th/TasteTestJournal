# Taste Test Journal

A simple local-first web app for tracking cannabis strains you try.

## Features

- Log strain name, purchase date, packaged date, rating, notes, THC %, CBD %, and terpenes %.
- Add custom percentage fields (for example CBG, CBN, etc.).
- Store data in browser `localStorage`.
- Dashboard-first layout with search, filters, and sorting.
- Quick outbound search links for Canna Cabana and Delta 9.

## Run locally

```bash
python3 -m http.server 4173
```

Then open <http://localhost:4173>.
